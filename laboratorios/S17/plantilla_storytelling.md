## 2. Mensaje único
> **Una sola frase** que la audiencia pueda repetir mañana.
> Fórmula: *«Recomendamos [acción] porque [evidencia principal], lo que supone [beneficio cuantificado], con la precaución de [límite clave].»*

**Nuestro mensaje único:** ______

**Test del ascensor (20 segundos):** decidlo en voz alta a alguien que no conoce el proyecto. ¿Lo repite con sus palabras? ☐ sí ☐ no → reescribid.

## 3. Pirámide de la comunicación (de arriba abajo)
La **conclusión primero**. Después, 3 argumentos. Después, la evidencia de cada argumento.

```
                 CONCLUSIÓN / RECOMENDACIÓN
                (el mensaje único, arriba)
        ┌─────────────┬─────────────┬─────────────┐
   ARGUMENTO 1   ARGUMENTO 2   ARGUMENTO 3
   (por qué      (cómo lo       (qué límites
    importa)      sabemos)       y riesgos)
        │             │             │
   Evidencia     Evidencia     Evidencia
   (dato, figura) (dato, figura) (dato, figura)
```

| Nivel | Contenido | Evidencia (figura / tabla de la memoria) |
|---|---|---|
| **Conclusión** | | |
| **Argumento 1** (por qué importa: problema y valor) | | |
| **Argumento 2** (cómo lo sabemos: método y resultados) | | |
| **Argumento 3** (qué límites y riesgos hay, y qué proponemos) | | |

**Regla de agrupación:** cada argumento resume su evidencia; si un dato no sostiene un argumento, **se queda fuera** (va a la memoria).

## 4. Arco narrativo
Una historia tiene un protagonista, un problema y un cambio. **El protagonista es el cliente / usuario, no el modelo.**

| Momento | Pregunta que responde | Nuestro contenido | Tiempo |
|---|---|---|---|
| **1. Situación** | ¿Cuál es el mundo actual del cliente? | | 1 min |
| **2. Complicación** | ¿Qué problema o coste aparece? ¿Por qué duele? | | 1 min |
| **3. Pregunta** | ¿Qué necesitamos saber para decidir? | | 0,5 min |
| **4. Resolución** | ¿Qué hicimos y qué encontramos? (baseline → mejora; el gráfico clave) | | 3-4 min |
| **5. Demostración** | ¿Cómo se usa? (el momento «ajá») | | 2-3 min |
| **6. Límites y riesgos** | ¿De qué **no** fiarse? ¿Qué hicimos para mitigarlo? | | 1 min |
| **7. Llamada a la acción** | ¿Qué proponemos al cliente que haga **el lunes**? | | 1 min |

## 5. Storyboard (máximo 12 diapositivas)
Una diapositiva = **una idea**. El **título es la conclusión** (frase, no etiqueta). Máximo ~25 palabras por diapositiva; el gráfico cuenta, el orador explica.

| Nº | Título-conclusión | Elemento visual | Persona que habla | Tiempo |
|---|---|---|---|---|
| 1 | Mensaje único + equipo | Titular y logo | | 0:45 |
| 2 | El problema del cliente (situación + complicación) | Una escena o cifra | | 1:00 |
| 3 | La pregunta y la decisión | Esquema simple | | 0:30 |
| 4 | Los datos que tenemos (y sus límites) | Una figura del EDA | | 1:00 |
| 5 | Cómo lo hicimos (enfoque en 3 pasos) | Diagrama del proceso | | 0:45 |
| 6 | Resultado clave frente al baseline | Gráfico principal | | 1:15 |
| 7 | Por qué funciona (interpretación) | Importancia / SHAP / Grad-CAM | | 1:00 |
| 8 | Demostración | Pantalla de la demo / vídeo plan B | | 2:30 |
| 9 | Dónde falla y para quién (sesgos) | Tabla o gráfico por subgrupo | | 0:45 |
| 10 | IA responsable: riesgos y medidas | 3 riesgos, 3 medidas | | 0:45 |
| 11 | Qué proponemos al cliente | 3 acciones priorizadas | | 1:00 |
| 12 | Cierre: mensaje único + contacto | Frase repetida | | 0:30 |

*(Sin diapositiva «Gracias / ¿Preguntas?» vacía: la 12 ya es el cierre. Las diapositivas de reserva van **después**, como apéndice para preguntas.)*

## 6. El pitch de 3 minutos
Versión ultracorta para un directivo con poco tiempo. Debe funcionar **sin diapositivas**.

| Segundos | Contenido | Nuestra frase |
|---|---|---|
| 0-20 | **Gancho**: dato o escena | |
| 20-50 | **Problema** y quién lo sufre | |
| 50-100 | **Solución**: qué hicimos, en lenguaje llano | |
| 100-150 | **Resultado**: la cifra que importa frente a lo que hay hoy | |
| 150-170 | **Límite** honesto | |
| 170-180 | **Petición**: qué necesitamos que decida | |

## 7. Técnicas para que se recuerde
- **Una cifra grande** por diapositiva («−17 000 €», «3 de cada 4»).
- **Comparación** siempre («frente a lo que hacemos hoy»).
- **Analogía** cotidiana para lo técnico.
- **Regla de tres** (tres argumentos, tres riesgos, tres acciones).
- **Silencio** tras la cifra clave (2 segundos).
- **Contacto visual** con el público, no con la pantalla; no leer.
- **Honestidad**: contar un fallo y qué aprendisteis lo hace creíble.
