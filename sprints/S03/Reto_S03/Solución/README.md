# Solución del reto S03 «Primer modelo en producción»

Una forma correcta de resolver el reto, para **comparar con la vuestra y debatir en clase**. No es la única ni es perfecta (los datos son sintéticos y los importes de coste, de ejemplo). Ábrela **después de entregar**.

| Fichero | Qué es |
|---|---|
| [`INFORME_RESUELTO_Reto_S03.md`](INFORME_RESUELTO_Reto_S03.md) | El informe resuelto (3 partes), la revisión con la rúbrica, **«De dónde salen los datos»** y preguntas para debatir |
| [`calcular_cifras_informe.py`](calcular_cifras_informe.py) | Reproduce las cifras que no imprime el laboratorio (SQL, sensibilidad de costes, sesgos, capacidad limitada). Se ejecuta **después** de `S3.5_lab_autogluon.py`, en la misma carpeta |
| [`evidencias/`](evidencias/) | Salida del laboratorio, cifras, llamadas reales a la API (`captura_api.txt` y las dos reservas `reserva_*.json`) y prueba de cierre |

**Para repetirlo:** copia el script y las dos reservas en la carpeta del laboratorio ([`../laboratorio_automl/`](../laboratorio_automl/)), ejecuta allí el laboratorio y después `python calcular_cifras_informe.py`. Los pasos completos están en «De dónde salen los datos».

Volver a la [ficha del reto](../Reto_Sprint_03.md).
