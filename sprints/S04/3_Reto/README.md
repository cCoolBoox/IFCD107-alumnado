# 3 · Reto

Una carpeta por momento, en este orden:

1. [`1_Trabajar/`](1_Trabajar/) — **lo que tienes abierto mientras haces el reto**: el índice de las seis misiones con una **tarjeta por misión** (`tarjetas/`) y `reto_herramientas/` (la plantilla y los ejercicios).
2. [`2_Entregar/`](2_Entregar/) — **lo que subes y cómo se evalúa**: qué ficheros se suben, los requisitos, la rúbrica y la hoja de autoevaluación y coevaluación.
3. [`3_Consultar/`](3_Consultar/) — **la ficha completa**, solo para cuando algo no esté claro (qué pide el cliente, recursos del reto y reglas de la IA).
