# 🔑 Juego «Primer día de trabajo»

Acabáis el curso y os llegan problemas reales: una panadería que tira pan, un ayuntamiento desbordado de quejas, un buscador que no encuentra zapatillas…
En cada sala tenéis que averiguar **qué tipo de problema es y cómo resolverlo**, en cinco pasos (problema, datos, modelo, cómo medirlo, cómo contarlo).
En cada paso hay **4 opciones y solo una buena**. Cada sala superada da una palabra; con las ocho abrís la puerta.

**Cómo jugar:** descargad [`Juego_Primer_dia_de_trabajo.html`](Juego_Primer_dia_de_trabajo.html) (botón «Download raw file» de GitHub) y abridlo con el navegador. No necesita internet ni instalar nada. Se puede jugar desde el móvil.

- Se juega en equipo de 3–4, hablando antes de pulsar.
- Fallar no es grave: la explicación de por qué no sale al momento, pero cada fallo resta un punto.
- Al terminar cada sala os llevaréis una **ficha** con las cinco decisiones correctas.
