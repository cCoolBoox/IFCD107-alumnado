# 🎮 Juegos del curso

▶ **[Abrir el panel online](https://ccoolboox.github.io/IFCD107-alumnado/sprints/S12/2_Practica/juegos/)**: enlaza todos los juegos y los retos exprés. Funciona en el navegador, también desde el móvil.

> En GitHub un archivo `.html` solo se ve como código: usad el enlace de arriba. Para jugar sin conexión, descargad la carpeta `juegos/` completa y abrid `index.html`.

| Juego | Para qué sirve | Carpeta |
|---|---|---|
| 🔑 Primer día de trabajo | **Decidir**: 8 situaciones reales, 5 pasos con 4 opciones y solo una buena | [`primer_dia/`](primer_dia/) |
| 🕵️ Detective de pipelines | **Diagnosticar** un workflow con un resultado sospechoso | [`detective_pipelines/`](detective_pipelines/) |
| ⚔️ Duelos de modelo | **Interpretar cifras reales** de los cuadernos y elegir el titular honesto | [`duelos_de_modelo/`](duelos_de_modelo/) |
| 🧩 Taller de workflows | **Montar** el workflow de cada modelo del curso (23 puzzles) | [`taller_workflows/`](taller_workflows/) |
| 💶 Subasta de presupuesto | **Priorizar** con horas limitadas | [`subasta_presupuesto/`](subasta_presupuesto/) |
| 🃏 Memorama de modelos | **Repasar el mapa** de modelos (24 parejas) | [`memorama_modelos/`](memorama_modelos/) |
| 🎤 Entrevista de trabajo | **Explicar** en voz alta, con tarjetas imprimibles | [`entrevista_trabajo/`](entrevista_trabajo/) |
| 📑 El informe | **Juego final**: reunir, analizar, sintetizar y transcribir un informe | [`el_informe/`](el_informe/) |
| 📺 Duelo en directo | Concurso para **proyectar** en clase (lo dirige el docente) | [`duelo_en_directo/`](duelo_en_directo/) |

- No necesitan internet ni instalar nada. Se pueden jugar desde el móvil.
- Sin conexión: descargad la carpeta `juegos/` completa (los enlaces del panel son relativos) y abrid `index.html`.
- El progreso se guarda en vuestro navegador.
- 🎓 Para cerrar el curso: [**Nueve juegos, nueve enseñanzas**](../../../../material/9.%20Nueve_juegos_nueve_ensenanzas.md).
