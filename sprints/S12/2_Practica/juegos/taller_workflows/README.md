# 🧩 Juego «Taller de workflows»

Cada puzzle es un **modelo del curso** (regresión, árboles, K-means, redes, CNN, series, texto, RAG, autoencoders…).
Vuestro trabajo: **montar su workflow**, de arriba abajo, pulsando las piezas en el orden correcto. Ojo: en cada puzzle se cuelan **dos piezas trampa** que no van.

**Cómo jugar:** descargad [`Taller_de_workflows.html`](Taller_de_workflows.html) (botón «Download raw file» de GitHub) y abridlo con el navegador. No necesita internet ni instalar nada. Se puede jugar desde el móvil.

- **Comprobar**: verde = bien; ámbar = pieza buena en otro sitio; rojo = trampa (explica por qué).
- 5 puntos por puzzle, −1 por cada fallo y −1 por la pista.
- Al terminar cada puzzle os quedáis con el workflow explicado paso a paso: **es vuestro chuletario de repaso**.
