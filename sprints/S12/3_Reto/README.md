# 3 · Reto

Una carpeta por momento, en este orden:

1. [`1_Trabajar/`](1_Trabajar/) — **lo que tienes abierto mientras haces el reto**: el reto en una página (lo esencial, con los tres niveles) y, si el reto las lleva, las plantillas y los datos.
2. [`2_Entregar/`](2_Entregar/) — **lo que subes y cómo se evalúa**: qué ficheros se suben, los requisitos, la rúbrica y la hoja de autoevaluación y coevaluación.
3. [`3_Consultar/`](3_Consultar/) — **para consultar**: la ficha completa del reto (qué pide el cliente, recursos, guía paso a paso, uso de la IA y errores frecuentes).
