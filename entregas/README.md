# Entregas de los equipos

Cada equipo trabaja en su propio repositorio y enlaza aquí sus entregas de cada sprint.
Estructura recomendada del repositorio de equipo:

```
README.md          # problema, equipo y cómo ejecutar
requirements.txt
data/              # solo datos con licencia y sin datos personales (o script de descarga)
notebooks/
src/
docs/              # ficha de proyecto y memoria técnica
```
