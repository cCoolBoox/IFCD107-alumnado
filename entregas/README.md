# Entregas

**Cada equipo entrega en su propio repositorio de GitHub.** En esta carpeta no se sube nada: solo está [`equipos.md`](equipos.md), la lista con el repositorio de cada equipo.

- **Crear el repositorio** (Sprint 0, una vez): [actividad del Sprint 0](../sprints/S00/actividades/actividad_repositorio_equipo.md).
- **Guía paso a paso para subir archivos:** [Cómo subir vuestras respuestas a GitHub](../material/5.%20Como_entregar_en_GitHub.md).
- **Entregar cada sprint:** sube tu entregable a la carpeta `sprint-XX/` del repositorio de tu equipo (*Add file → Upload files → Commit changes*) y rellena su `README.md`: qué se entrega, quién hizo qué y cómo reproducirlo.
- **Cuándo:** antes del cierre del sprint (la fecha está en su ficha de reto).
- **Siempre:** todos los integrantes aparecen en el historial, y **nunca** se suben claves, contraseñas ni datos personales.
